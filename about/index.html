海鸥桌面（SeagullLauncher）

一款面向安卓车机的多窗口桌面。对标海鸥桌面（cn.wayecai.launcher v1.7.3）的功能结构，去掉账号、会员与云端体系，做成一个装上就能用的普通桌面。

它解决什么问题

开车时真正要看的只有几样：路怎么走、歌是什么、几点了。海鸥桌面把导航、音乐、时钟、车况钉在同一块屏幕上，其余的都收进抽屉。

核心能力

  • 画中画与多窗口：L2 系统画中画（标准 PiP，无 root 可用）；L3 虚拟屏（MediaProjection 建私有虚拟屏 + root 搬运第三方应用 + 触摸注入）
  • 导航信息卡：读取高德导航状态，转向 / 距离 / 到达时间实时上桌面，支持回家 / 公司一键导航并自动落画中画
  • 杀后台自愈：后台被清理后回桌面自动拉活并重搬画中画；悬浮球长按手动自愈菜单
  • 桌面定制：14 套主题、日夜切换、全局字号、Dock 栏 / 快捷栏 / 菜园、动态壁纸、海鸥岛、拼音搜索、小白点悬浮球
  • 天气与歌词：Open-Meteo 天气卡片；媒体会话歌词三来源匹配 + 底栏音乐条
  • 系统增强层（root 可选）：触摸跨屏转发、任务搬运、亮度音量、Wi-Fi / 蓝牙 / 飞行模式、强停清缓存、CPU / 温度 / 内存、OBD-II 车况引擎

设计原则

  1. 公开优先 —— 核心功能只用标准公开 API；特权能力「有则增强，无则隐藏」
  2. 单一事实源 —— 所有配置收在一处（LauncherModel），UI 只读写这一处
  3. 无账号 —— 不登录、不会员、不上云，备份恢复只走本地文件
  4. 可逆 —— 每个副作用都能随开关关闭而撤销

技术

  • 包名 com.seagull.carlauncher，最低 Android 10（API 29），targetSdk 33
  • 纯命令行构建（无 Gradle）：aapt2 → javac → d8 → apksigner
  • 仅供学习交流，请勿用于商业用途
