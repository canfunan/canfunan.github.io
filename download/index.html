环境要求

  • Android 10（API 29）及以上，车机或手机均可安装
  • 不需要 root 即可使用；root / 无障碍 / 截屏授权是可选增强层，缺失时对应入口自动隐藏
  • 可选：LSPosed 作用域内勾选本应用（hook 增强功能）

安装

  1. 下载 APK 传入设备安装（车机建议先拷到 /data/local/tmp 再 pm install -r）
  2. 首次进入按引导授权，可选开启 root 增强
  3. 设置 → 应用 → 默认桌面 → 选「海鸥桌面」，或桌面内「设置 → 设为默认桌面」

激活与试用

  • 安装后默认试用 3 天，期间功能完整可用
  • 到期后需要授权码继续使用：加 QQ 群 95155696，联系管理员「小子」购买授权码
