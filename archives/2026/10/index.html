海鸥桌面

多窗口车机桌面 —— 画中画导航、桌面信息卡、杀后台自愈。

对标海鸥桌面（v1.7.3）的功能结构，去掉账号、会员与云端，做成一个装上就能用的普通桌面。不需要 root 即可安装使用；root、无障碍、截屏授权是可选增强层，缺失时自动隐藏对应入口，绝不因此崩溃。

真机一览

为驾驶而设计

开车时真正要看的只有几样：路怎么走、歌是什么、几点了。海鸥桌面把这些钉在同一块屏幕上，其余的都收进抽屉。它参考 vivo 智能车载 CarLauncher 的交互结构，围绕「驾驶时看什么、点什么最少」设计。

画中画与多窗口

两档窗口能力：L2 系统画中画走标准 PiP API，无 root 可用；L3 虚拟屏通过 MediaProjection 建私有虚拟屏，用 root 把任意第三方应用搬上去，再注入触摸事件——高德、百度、网易云都能进画中画，横竖屏语义自动修正。

导航信息卡

直接读取高德导航状态，转向箭头、剩余距离、预计到达实时上桌面卡片，与车机屏同步。支持「回家 / 公司」一键起导航，起完自动落进画中画。

杀后台自愈

后台被一键清理，回桌面自动拉活目标应用并重搬画中画；悬浮球长按还有手动自愈菜单——自愈全部 / 自愈画中画一 / 自愈画中画二，指哪打哪。

桌面随你摆

14 套主题、日夜切换、全局字号；Dock 栏、快捷栏、菜园（常用联系人/应用）三种摆法；动态壁纸、海鸥岛、文件夹、拼音搜索、小白点悬浮球，桌面每个角落都可配置。

天气与歌词

Open-Meteo 公开接口的天气卡片；歌词走媒体会话三来源匹配，底栏音乐条随时显示正在播放什么，还能控制上一首 / 暂停。

系统增强层（可选）

root 在位时解锁：触摸跨屏转发、任务窗口搬运、亮度音量、Wi-Fi / 蓝牙 / 飞行模式、强停与清缓存、CPU / 温度 / 内存读数、OBD-II 车况引擎。没有 root，这些入口自动隐藏，不影响其它功能。

设计原则

  • 公开优先 —— 核心功能只用标准公开 API；特权能力做成「有则增强，无则隐藏」。
  • 无账号 —— 不登录、不会员、不上云；备份与恢复只走本地文件。
  • 可逆 —— 每个副作用（服务、监听、悬浮窗、定时器）都能随开关关闭而撤销。
